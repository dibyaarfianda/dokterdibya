## 5. FAQ

**T: Apakah aplikasi mobile dokterDIBYA lama masih bisa dipakai?**

J: Tidak. Aplikasi mobile versi lama sudah dinonaktifkan agar semua pasien menggunakan akses terbaru melalui PWA SISIwanita.

**T: Apakah akun lama saya tetap bisa digunakan?**

J: Ya. Pasien tetap bisa login menggunakan akun yang sama melalui sisiwanita.id.

**T: Apakah perlu install aplikasi dari Play Store?**

J: Tidak perlu. Cukup buka sisiwanita.id dari Chrome/Safari. Jika ingin seperti aplikasi, tambahkan ke layar utama HP.

**T: Kenapa dipindah ke PWA?**

J: PWA lebih ringan, aman, dan pembaruan fitur bisa langsung diterima tanpa pasien perlu update aplikasi manual.

**T: Bagaimana jika saya masih membuka dari aplikasi lama?**

J: Aplikasi lama akan menampilkan arahan untuk membuka sisiwanita.id. Silakan hapus aplikasi lama dan gunakan PWA SISIwanita.

- **Alasan:** Lebih ringan, aman, dan update fitur langsung diterima.
