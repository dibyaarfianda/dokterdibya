# Anvil Page Structure

Reference: https://anvil.framer.media/

## Site Map

| Page | URL | Purpose |
|------|-----|---------|
| Home | `/` | Landing page — hero, features, services, CTA |
| Pricing | `/pricing` | Plan comparison with tiers |
| About | `/about` | Company/team information |
| Contact | `/contact` | Contact form and info |
| 404 | (auto) | Error page |

## Homepage Sections (Top to Bottom)

### 1. Navigation Bar
- Fixed position, frosted dark glass
- Logo left, nav links center, CTA right
- Hamburger menu on mobile (column layout)
- Height: ~64px

### 2. Hero Section
- Full-width dark gradient background
- Large decorative circle element (674px, absolute positioned)
- Display heading (48-72px bold)
- Supporting description text
- Email input + CTA button
- Height: 600px desktop, min-content mobile

### 3. Social Proof / Logos Row
- Horizontal row of brand/partner logos
- Subtle, low-opacity white logos on dark bg
- Builds trust and credibility

### 4. Features / Services Grid
- 3-column grid (desktop), stacking on mobile
- Each feature: icon + title + description
- Clean card layout with subtle borders
- Section title with uppercase label above

### 5. Detailed Feature Showcase
- Alternating layout: text left / visual right, then flip
- Large heading + body text + CTA
- Supporting image or screenshot
- Generous spacing between blocks

### 6. Testimonials / Social Proof
- Quote cards with client attribution
- Photo, name, role, company
- Potentially carousel or grid layout

### 7. Pricing Section
- Three tier layout
- Plan name, price, feature list, CTA button
- Most popular plan highlighted (border or badge)
- Feature comparison list

### 8. FAQ / Support Section
- Accordion/collapsible items
- Question as trigger, answer as body
- Clean dividers between items

### 9. Final CTA Section
- Dark elevated section
- Bold heading
- Email input + button
- Reinforces conversion

### 10. Footer
- Centered alignment
- Logo + tagline
- Navigation link columns
- Social media icons
- Copyright text
- Minimal, clean treatment

## Design Principles Observed

1. **Content hierarchy** — Each section has a clear label → heading → body → CTA flow
2. **Breathing room** — Generous spacing between sections (40-80px+)
3. **Visual rhythm** — Alternating content patterns prevent monotony
4. **Conversion-focused** — CTA buttons appear at multiple touchpoints
5. **Dark elegance** — Monochromatic palette with single accent color
6. **Editorial feel** — Uppercase labels, wide letter-spacing, tight heading tracking
7. **Minimal decoration** — Only the hero circle as decorative element; rest is pure content
